# QA Knowledge Base Dataset (By-Source Branch)

Ця гілка репозиторію реалізує підхід **"by-source" (за джерелами)**. 
Тут структура папок датасету повністю повторює оригінальну ієрархію першоджерела (наприклад, навігаційне меню сайту).

## Інструмент збору (`tools/pipeline.py`)

Для автоматизації збору використовується власний ETL-скрипт, адаптований під цей підхід:
1. **Discover:** Скрипт парсить навігаційне меню сайту (багатоступеневі `ul`/`li`) і формує структуру шляхів типу `qalight.ua/category/subcategory`. 
2. **Classify:** LLM-аналіз (Gemini API) використовується виключно як фільтр. Модель відкидає нерелевантні ІТ-статті (чиста розробка, залізо), залишаючи лише QA-контент. Алгоритм ковзного вікна захищає від блокувань API (5 запитів/хв).
3. **Download:** Асинхронне завантаження, очищення HTML від реклами/навігації та збереження у Markdown зі збереженням оригінальної структури першоджерела.

### Залежності та запуск
Для етапу класифікації потрібна змінна середовища:
`export GEMINI_API_KEY="ваш_ключ"`

Запуск пайплайну:
```bash
python tools/pipeline.py -h
```
