**На курсі «Java для автоматизаторів»** – ви отримаєте всі необхідні знання з мови програмування Java для того, щоб почати автоматизувати. Отримані теоретичні знання одразу ж закріплюються практикою. У курс входить:

__Пройшовши__ __цей курс Ви отримаєте__ практичний досвід у використанні мови програмування Java як інструменту для написання автотестів.

__Додаткова інформація:__

Автоматизатори і розробники хоч і користуються деякими однаковими інструментами, проте все ж вимагають різного рівня підготовки. Це стосується і вивчення мови програмування Java. В першу чергу автоматизор використовує Java як інструмент для написання автотестів. Цей підхід передбачає більш низький початковий рівень, необхідний для виконання щоденної роботи. Звичайно ж, чим глибше знання мови програмування, тим вищий ваш рівень як фахівця. Однак не варто забувати, що це твердження стосується не лише одного інструмента (Java), а й Jenkins, SQL, Maven тощо. Тому бажано приділяти рівну кількість часу усім інструментам. Цей курс і покликаний дати ті знання в інструменті Java, які дозволять складати тести, робити перевірки, користуватися різними бібліотеками тощо.

Також у курс включена лекція з ООП – ця теорія може бути застосована не лише щодо Java, а показує основу всіх сучасних об’єктно-орієнтованих мов. Саме розуміння її дає відмінний потенціал для подальшого розуміння мови програмування.

Новинкою цього курсу є лекція зі складання блок-схем. Будь-який процес можна розкласти на послідовність певних дій і варіантів їх розгалудження. Якраз на цій лекції ми і створимо блок-схему, за якою на наступних лекціях і будемо писати нашу першу Java програму.
