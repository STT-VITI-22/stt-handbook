# QA Bible Dataset

## Метод парсингу
Дані отримані безпосередньо з серверів GitBook. Замість парсингу HTML (веб-скрейпінгу), використано вбудовані можливості GitBook для експорту в Markdown.

## Використані засоби та процес
- **Інструменти:** `httpx` (асинхронні запити), вбудовані ендпоінти GitBook (`llms.txt` та `.md`).
- **Процес:** 
  1. Завантаження `llms.txt` для отримання повного списку існуючих сторінок.
  2. Асинхронне завантаження сирого Markdown-коду для кожної сторінки через `.md` ендпоінти.
  3. Нормалізація посилань на зображення (заміна відносних шляхів `/files/...` на абсолютні URL).
  4. Видалення системних технічних блоків GitBook (наприклад, посилань на сам `llms.txt` в шапці файлу).
