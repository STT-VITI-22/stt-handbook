# Dataset: Articles

This directory contains raw, authoritative source materials grouped by their domain (source).

## Structure
* `/ibm/` - IBM Knowledge Base topics.
* `/martin_fowler/` - Architectural patterns from Martin Fowler's blog.
* `/cncf/` - Cloud Native Computing Foundation whitepapers.
* `/opentelemetry/` - Official OpenTelemetry documentation.
* `/slsa/` - SLSA framework specifications.
* `/principles_of_chaos/` - Chaos Engineering principles.
