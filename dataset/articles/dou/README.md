# DOU / QALight Dataset

## Метод парсингу
Класичний веб-скрейпінг (DOM-парсинг) статей з форумів та баз знань.

## Використані засоби та процес
- **Інструменти:** `httpx` (завантаження HTML), `BeautifulSoup4` (аналіз DOM), `markdownify` (конвертація HTML у Markdown).
- **Процес:** 
  1. Завантаження HTML-коду сторінки.
  2. Виділення головного контейнера зі статтею (видалення навігації, сайдбарів, секцій коментарів, рекламних блоків).
  3. Конвертація відфільтрованого HTML-дерева у формат Markdown за допомогою бібліотеки `markdownify`.
  4. Збереження оригінальних посилань на вбудовані зображення та форматування коду.
