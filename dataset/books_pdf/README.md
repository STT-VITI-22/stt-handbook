# PDF Books Dataset

## Метод парсингу
Конвертація технічної літератури з формату PDF у Markdown. Через складність верстки книг та обмеження API, наразі використовується посторінковий метод екстракції.

## Використані засоби та процес
- **Інструменти:** `PyMuPDF` (екстракція сирого тексту та зображень), `Gemini API` (генерація Markdown).
- **Процес:** 
  1. Вилучення тексту та растрових графічних елементів (XObjects) з кожної сторінки за допомогою PyMuPDF.
  2. Відправка сирого тексту та візуального контексту сторінки до LLM (Gemini).
  3. LLM намагається відтворити логічну структуру (заголовки, списки, таблиці) та відфільтрувати колонтитули.
- **Відомі обмеження:** Посторінковий підхід спричиняє розрив контексту речень на стиках сторінок. Альтернативний підхід із семантичним об'єднанням сторінок (chunking) був призупинений через ліміти на вихідні токени LLM та порушення порядку читання блоків.
