# PPTX / Презентації Dataset

## Метод парсингу
Дані отримані шляхом структурного та семантичного парсингу презентацій PowerPoint (збережених у форматі PDF). Процес базується на комбінації програмного розбору верстки та обробки тексту великими мовними моделями (LLM).

## Використані засоби
- **PyMuPDF (`fitz`)**: Для низькорівневого вилучення тексту та растрових об'єктів у форматі словників (`dict`), що дозволяє аналізувати фізичні координати та атрибути кожного елемента.
- **Gemini API**: Для фінального очищення сирого тексту, відновлення форматування (списків, таблиць) та видалення залишків інституційного сміття (назви університетів тощо).

## Детальний алгоритм обробки

1. **Екстракція блоків:**
   Кожна сторінка аналізується на рівні блоків (текстових та графічних) за допомогою `get_text("dict")`. Це дозволяє отримати доступ до розміру шрифту, координат та властивостей зображень. Текст витягується з параметром `sort=True` для збереження фізичного порядку читання (згори вниз, зліва направо).

2. **Фільтрація графіки (Дедуплікація):**
   - Усі знайдені зображення фільтруються за площею (відкидаються дрібні об'єкти, лінії, тіні).
   - Кожне зображення хешується за алгоритмом MD5. Якщо ідентичний хеш зустрічається на кількох слайдах (наприклад, водяні знаки або логотипи установ), зображення ідентифікується як фонове сміття і видаляється.

3. **Розпізнавання заголовків:**
   Скрипт аналізує всі текстові блоки на сторінці. Заголовок визначається за двома критеріями: найбільший розмір шрифту (у межах 4pt від максимального на слайді) та найвище фізичне розташування на сторінці (мінімальна координата Y).

4. **Семантичне об'єднання (Chunking):**
   Щоб уникнути розриву речень на стиках слайдів, застосовується алгоритм `SlideChunker`. Він послідовно збирає слайди в одну групу (Chunk), поки не зустріне новий заголовок. Таким чином формуються логічні розділи.

5. **LLM-нормалізація:**
   Сформований сирий текст передається до Gemini API разом із чіткою інструкцією: зберегти оригінальну розбивку на речення (без злиття), відформатувати списки/код і видалити специфічні для навчальних закладів колонтитули, зберігаючи технічний зміст.
