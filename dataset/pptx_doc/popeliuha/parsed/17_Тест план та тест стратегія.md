# Основна відмінність між Policy, Стратегією та Планом

* **Test policy**: Документ на рівні організації.
* **Test strategy**: Документ на рівні аплікації (застосунку, продукта, веб-сайта).
* **Test plan**: Документ на рівні 1 фічі, 1 релізу, 1 модуля, 1 продукта.

# Test Policy

* Окреслено переваги тестування, цінність бізнесу, яку надає організація
* Визначено цілі тестування, такі як підвищення впевненості в якості, виявлення дефектів і зниження ризиків
* Описано методи вимірювання ефективності тестування та результативності виконання завдань тесту
* Підсумовано процеси, які використовуються при тестуванні за допомогою первинного процесу тестування ISTQB
* Описано способи, якими організація може покращити свої процеси тестування

# Test Strategy

* Test Strategy Id
* Introduction – короткий опис цілі і складу документу
* Standards to use
* Risks and Mitigations – ризики, пов'язані з тестуванням і шляхи їх вирішення
* Entry Criteria – набір передумов, що повинні бути виконані перед початком тестування
* Exit Criteria – критерії, що визначають, коли тестування може бути припинене
* Test design techniques
* Test environment
* Configuration management of testware – специфікація з вказаними версіями програми, яку тестуємо
* Test process improvement – підходи для покращення процесів тестування
* Approvals

# Test Plan

* Id
* Introduction
* Test items
* Features to be tested and features not to be tested
* Test approach
* Pass/fail criteria
* When testing should be stopped
* Test deliverables - яка документація буде результатом тестування
* Tasks and responsibilities
* Environmental needs
* Training and staffing needs
* Schedule
* Risks
* Approvals

| Тест План | Тест Стратегія |
| :--- | :--- |
| Створює Test Manager або Test Lead | Створює Project Manager |
| В деталях описує об'єм тестування і дії, необхідні для проведення тестування | Високорівневий (не детальний) документ з інструкціями про те, як буде проходити тестування |
| Описує всі активності тестування: які використовувати техніки, графік, ресурси тощо | Поверхньо описує техніки, що будуть використовуватись, систему для тестування тощо |
| Тест плани можуть бути змінені і оновлені | Тест стратегію зазвичай не змінюють |
| Тут багато деталей та уточнень | Тут загальні підходи та методології |
