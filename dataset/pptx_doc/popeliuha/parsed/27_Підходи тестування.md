# Підходи тестування

| Позитивне | Негативне |
| :--- | :--- |
| Вводимо правильні дані, очікуємо хороший результат | Вводимо невірні дані, очікуємо повідомлення про помилку |
| Перевірка позитивного flow - обов'язкова | Всі негативні випадки протестувати неможливо, але пара ключових тестів - must have |

| Проактивне | Реактивне |
| :--- | :--- |
| Починається на ранніх стадіях | Відбувається на фазі тестування |
| Робимо все, щоб баги не з'явились | Реагуємо на існуючі баги |
| QA | QC |
| Процес | Продукт |

| Мануальне | Автоматизоване |
| :--- | :--- |
| Проводиться тестувальником вручну | Інженер пише код і програма проводить тестування |
