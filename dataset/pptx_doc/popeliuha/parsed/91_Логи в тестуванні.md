# Логи в тестуванні

![Знак попередження](images/91_Логи%20в%20тестуванні/page_1_img_1.jpeg)

## Логи

- це текстовий файл, в який програма, як в щоденник, записує все, що відбувається. Логи потрібні, щоб показати, де конкретно була помилка і що робила програма, коли помилка відбулась.

## Види логів

| Логи додатку | Логи ОС | Логи сервера |
| :--- | :--- | :--- |
| Браузер | Windows | Error log |
| Десктоп | Linux | Access log |
| Мобільні додатки | MacOS | |

## Рівні логів

* **Fatal** - логи про фатальні, критичні помилки
* **Error** - лог про помилку
* **Info** - будь-яка інформація (не помилки)
* **Warning** - попередження системи, низькопріоритетні помилки
* **Debug** - логи, що показуються при "дебазі". Схожі на info
