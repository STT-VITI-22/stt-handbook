# 42. Frontend та Backend простими словами

Source: https://www.youtube.com/watch?v=kcseoQjrLkQ

У цьому матеріалі детально розглядаються frontend, backend та зв'язок між ними.

Frontend — це клієнтська сторона користувацького інтерфейсу; це все, що браузер може читати, виводити на екран та запускати, а користувач — бачити. Frontend складається з HTML, CSS та JavaScript.

HTML (HyperText Markup Language) говорить браузеру, з чого складається сторінка: з якого тексту, яких кнопок, зображень, заголовків тощо, в якому вони порядку — тобто які саме елементи зображені на сторінці.

CSS (Cascading Style Sheets) говорить браузеру, як зображати елементи: наприклад, відступ вправо повинен бути на 10 пікселів, текст повинен бути чорного кольору і певного шрифту.

JavaScript говорить браузеру, як реагувати на деякі взаємодії: наприклад, при наведенні на кнопку змінюється колір, при натисканні з'являється певне вікно тощо.

Backend — це програмно-апаратна частина проєкту, це все, що працює на сервері. Сервер — це комп'ютер, що під'єднаний до мережі, який відповідає на повідомлення від інших комп'ютерів. Backend відповідає за обробку бізнес-логіки — тобто все, що відбувається «під капотом». Його можна писати багатьма мовами програмування, такими як Java, C#, Python, Ruby, PHP та JavaScript. Також можна використовувати різні системи управління базами даних, такі як MySQL, MSSQL, PostgreSQL, MongoDB та багато інших.

Для прикладу роботи backend, уявіть собі логін-форму, в якій необхідно ввести логін та пароль для входу в систему. Якщо ввести невірні дані, вони відправляться на backend. Користувач вводить їх у frontend, натискає кнопку відправлення, і дані відправляються на backend. На сервері ці дані валідуються і перевіряються: чи дійсно існує такий користувач. Якщо такий користувач є, перевіряється, чи правильний у нього пароль. Якщо пароль правильний, відбувається авторизація. Якщо пароль введений невірно, система відмовляє у доступі і повідомляє, що пароль неправильний. Після цього інформація повертається на frontend.

Тобто backend — це вся та «магія», що відбувається з програмами та сайтами після того, як користувач виконує певні дії. Таким чином можна наочно побачити, як виглядають і працюють frontend та backend.

Один із найпопулярніших способів взаємодії frontend та backend — це клієнт-серверна архітектура. У випадку клієнт-серверної архітектури HTTP-запити надсилаються безпосередньо на сервер програми, а сервер відповідає HTML-сторінкою.

Простими словами, коли користувач логіниться, відправляється запит до системи з логіном та паролем. Ця інформація обробляється, і після обробки сервер відповідає: або повідомляє про невірний пароль, відображаючи відповідну інформацію на HTML-сторінці, або авторизує користувача і перенаправляє на іншу HTML-сторінку, де показано статус успішного входу.

У будь-якому випадку сервер відповідає HTML-розміткою, яку видно на екрані. Між отриманням запиту та відповіддю сервер зазвичай шукає інформацію в базі даних (наприклад, чи існує такий користувач).

Коли сторінку завантажено в браузері, HTML визначає, що буде показано, CSS — як це буде виглядати, а JavaScript — які будуть особливі взаємодії.
