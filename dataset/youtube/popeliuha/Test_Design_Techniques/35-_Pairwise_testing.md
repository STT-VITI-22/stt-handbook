# 35. Pairwise testing

Source: https://www.youtube.com/watch?v=Wh5B6563MgA

Існує веб-сайт, який допомагає робити попарне тестування (pairwise testing) — pairwise.teremokgames.com . Основна суть полягає в тому, що генеруються тести із багатьох різних пар.

**Приклад 1: Тестування на різних системах**

Уявімо задачу: протестувати сайт на різних системах на максимальній кількості різних пар.

1. **Браузер**: тестуємо на різних браузерах (Chrome, Opera, Safari, Mozilla, Edge).
2. **Операційна система**: тестуємо на Windows, Linux, macOS.
3. **База даних**: на різних базах даних сайт буде працювати по-різному (наприклад, одна Oracle та одна Microsoft SQL).

Відповідно, є три різні умови з декількома варіантами (у браузера — 5 варіантів, у операційної системи — 3, у баз даних — 2). Після генерації отримуємо такі пари для тестування:
- Chrome, macOS, Oracle
- Chrome, Windows, MS SQL
- Chrome, Linux, Oracle
- Opera, Linux, Oracle
- Opera, Windows, MS SQL
та інші.

З отриманого списку потрібно видалити ті пари, які невалідні. Наприклад:
- Chrome на macOS не тестується — рядок видаляється.
- macOS Opera, macOS Mozilla, macOS Edge — також видаляються.
- macOS Safari — працює.
- Safari з Windows та Linux — навряд чи буде працювати, ці варіанти також видаляються.

Після видалення залишається 9 валідних варіантів, кожен із яких можна використовувати для тестування.

**Приклад 2: Тестування на різних категоріях людей**

Уявімо тест, у якому потрібно протестувати функціонал на різних людях. Люди поділяються за статтю, расою та віком:

- **Стать**: Male, Female, Other (ми толерантні, тому є стать — Other).
- **Раса**: три основні раси (афроамериканці, європейці, азіати).
- **Вік (Age)**: до 20, 21-50, від 50.

Після генерації (pairwise) отримуємо варіанти:
- Чоловіки, європейці, 50+
- Жінки, азіатки, 50+
- Жінки, європейки, менше 20 років
- Жінки, афроамериканки, середнього віку
- Люди, які захотіли не вказувати свою стать або змінили її (Other), європейці, середнього віку
і так далі.

**Pairwise testing vs All Combinations**

У попарному тестуванні (pairwise) генеруються не всі можливі варіанти, а лише унікальні комбінації пар. Метод All Combinations, навпаки, покриває абсолютно всі можливі комбінації.

Пояснення: якщо існує комбінація Male та European, і вона протестована один раз, її не потрібно тестувати повторно купу разів. Натомість потрібно тестувати European і середній вік, Male і середній вік. У pairwise кожна пара протестована один раз, і видалені всі зайві test cases.

All Combinations застосовується, якщо необхідно протестувати абсолютно все, але це буде надмірним тестуванням. Згенерувавши pairwise, тестується кожна пара. Наприклад, пара Male та European зустрічається один раз і більше не потрібна. Далі генеруються інші комбінації: European 20, Male 20, Male 50, Male 21-50, Male менше 20.

**Теоретична частина**

Попарне тестування (pairwise testing) — це методика систематичної комбінаторики тестів, котра забезпечує ефективне зниження кількості тестів для перевірки реакції системи на можливі комбінації значень її вхідних параметрів. 

Методика заснована на статистичному припущенні, що достатньо перевірити усі можливі значення пар вхідних параметрів для того, щоб виявити більшість дефектів системи, залежних від вхідних параметрів.

Основні цілі pairwise тестів:
1. Прибрати надлишкові перевірки. Якщо порівнювати два списки (більший з All Combinations і менший з pairwise), з більшого списку забираються всі надлишкові варіанти.
2. Забезпечити гарне тестове покриття, щоб покрити всі пари і виявити найбільшу кількість багів на мінімальному наборі тестів.
