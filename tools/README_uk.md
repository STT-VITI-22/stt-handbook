# База знань QA та Модульні Парсери

Репозиторій містить набір даних з QA-інженерії та набір парсерів для збору, конвертації та форматування матеріалів.

## Архітектура

Проєкт використовує модульну архітектуру. Замість одного універсального скрейпера, для кожного джерела даних створено окремий ізольований парсер, який враховує специфіку конкретного ресурсу. Точкою входу є `tools/main.py`.

### Парсери (`tools/parsers/`)
- **`qalight`**: Парсер бази знань QALight. Аналізує DOM для відтворення оригінальної ієрархії сайту, відфільтровуючи рекламні матеріали та сторінки курсів.
- **`dou`**: Парсер для форуму `dou.ua`. Завантажує вказані статті, видаляючи коментарі, блоки "поділитися" та інформацію про авторів.
- **`pdf`**: Локальний обробник, що використовує `pymupdf4llm` для масової конвертації PDF-файлів у Markdown зі збереженням структури таблиць, списків та заголовків.

Веб-парсери успадковуються від `BaseParser`, який забезпечує конвертацію HTML у Markdown (зі збереженням вбудованих зображень та екрануванням літеральних HTML-тегів).

## Використання

Запустіть скрипт із зазначенням цільового парсера:

```bash
uv run python tools/main.py qalight
uv run python tools/main.py dou
uv run python tools/main.py pdf
```

## Структура даних

Результати зберігаються у директорії `dataset/` із поділом за ресурсами:
- `dataset/qalight/`: Категоризовано за оригінальною навігаційною структурою сайту.
- `dataset/dou/articles/`: Статті з форумів.
- `dataset/books_pdf/`: Markdown-версії літератури з QA.
