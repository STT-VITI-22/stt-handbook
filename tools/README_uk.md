# Парсери Документації та База знань QA

Модульний інструментарій для парсингу складної технічної документації, книг, презентацій та веб-статей у чистий Markdown, готовий для LLM.

## Архітектура

Проєкт еволюціонував у модульну архітектуру. Головний фокус змістився на семантичне розбиття (chunking) та високоточну екстракцію складних документів (PDF, PPTX) за допомогою Gemini API.

### 1. Парсер Документів (`tools/doc_parser/`)
Основний рушій для обробки локальних файлів. Використовує комбінацію `PyMuPDF` для структурної екстракції та `Gemini API` для інтелектуального форматування в Markdown.

- **Режим презентацій (`--type pptx`)**: Витягує текст і зображення зі слайдів. Розумно фільтрує водяні знаки та повторювані фони. Використовує `SlideChunker` для семантичного об'єднання послідовних слайдів з однаковим заголовком у єдиний логічний розділ, щоб запобігти розриву речень на стику слайдів.
- **Режим PDF (`--type pdf`)**: Призначений для технічних книг. Використовує блоковий аналіз PyMuPDF (`dict`) для витягування ЛИШЕ відрендерених зображень (ігноруючи системні тіні/лінії). Має динамічний Fallback на режим OCR (розпізнавання з фотографій), якщо PDF є просто відсканованою книгою без текстового шару. Розбиває книги на блоки (макс. 5 сторінок) для запобігання перевантаженню API.

**Використання:**
```bash
# Парсинг презентації
uv run python tools/doc_parser/parse_docs.py "path/to/lecture.pdf" --type pptx

# Парсинг книги (векторної або сканованої)
uv run python tools/doc_parser/parse_docs.py "path/to/book.pdf" --type pdf
```

### 2. Веб-скрейпери (`tools/web_scrapers/`)
Ізольовані парсери для вебресурсів.
- **`qalight`**: Парсер бази знань QALight. Відфільтровує рекламні матеріали.
- **`dou`**: Парсер форуму `dou.ua`. Видаляє коментарі та UI-елементи.

### 3. Застарілі скрипти (`tools/legacy/`)
Містить старі монолітні парсери (напр., `gemini_pdf_parser.py`, `gemini_pptx_parser.py`). Збережено для історії та тестування крайових випадків.

## Структура даних

Результати обробки (Markdown файли) зберігаються у `dataset/`:
- `dataset/pptx/parsed/` — Форматовані технічні презентації.
- `dataset/books_pdf/parsed/` — Конвертована ІТ-література та книги з QA.
- `dataset/qalight/`, `dataset/dou/` — Статті, зібрані з вебресурсів.
